# System Requirements Specification: Formal Verification of Synchronized Infinity, 0.5-Pitch Square Composite Emergence, and Oppermann / Shifted Legendre Conjectures

## 1. System Overview and Architecture

This specification defines the Lean 4 formal verification framework under the `NaturalMathematics` namespace and the interactive visualization dashboard (HTML) comparing cumulative primes $\pi(n^2)$, cumulative composites $C(n^2)$, the linear baseline $2n - 2$, and Napier logarithmic density $n^2 / \ln(n^2)$ across $0.5$ and $1.0$ step resolutions.

### 1.1 Key Highlights

* **Separation of 1 and 2 via Prime Definition and Composite Emergence at 0.5 Square Pitch**:
  Peano-style generation of `1`, `2`, $\dots$ alone cannot distinguish the prime status of `1` and `2`, so the prime definition (`Nat.Prime`) is used to separate `1` (non-prime, $\neg \text{Nat.Prime } 1$) from `2` (first prime, $\text{Nat.Prime } 2$). Building on this, `composite_emergence_half_step_inevitability` proves that no composite (`IsComposite`) exists in the initial `1-2` regime ($m \le 2$), advancing by a $0.5$ square pitch into `1-2-3-4` ($2^2 = 4$) first produces the minimal composite $4 = 2^2$, and $n^2$ is composite for every $n \ge 2$.

* **Clean Propositional Proofs Without Custom Axioms or Internal Assumptions**:
  Custom axioms, `sorry` placeholders, and redundant bundling structures are excluded, proving `synchronized_infinity_principle`, `SynchronizedInfiniteTree1D`, `quadrilateral_theorem`, and `capacity_equilibrium_holds` ($\log_n(n^2) = 2$) as standalone propositions and theorems.

* **Implicational Connection to Oppermann and Shifted Legendre Conjectures**:
  Assuming `OppermannConjectureStatement`, the framework proves that both left and right prime slots (`oppermann_left_energy_slots` and `oppermann_right_energy_slots`) have cardinality at least `1` (`oppermann_slots_nonempty_of_conjecture`) and derives `ShiftedLegendreConjectureStatement` (`prove_shifted_legendre_of_oppermann`).

## 2. Lean 4 Formal Verification Specification (`NaturalMathematics`)

### Step 1: Synchronized Infinity and 1D Tree

* `synchronized_infinity_principle`: Proves infinitude directly without external assumptions via the injective successor map $f(x) = x + 1$ and the unreached element `0`.

* `SynchronizedInfiniteTree1D`: Inductive definition of 1D progression from `root` ($n = 1$) via `step`.

* `generation1D` / `generation_sync_1d_lt_value`: Proves by induction that tree generation depth always satisfies `generation1D t < n`.

* `ramanujacharyulu_synchronized_1d_tree`: Proves that for every $n \ge 1$, there exists a tree satisfying `generation1D t = n - 1 ∧ generation1D t < n`.

### Step 2: Square Geometry, Prime Separation (1 vs 2), 0.5-Pitch Composite Emergence, and Log Equilibrium

* `quadrilateral_theorem`: For $2 \le n$, proves $n^2 = n(n - 1) + n$, $n(n + 1) = n^2 + n$, and $(n - 1)^2 < n(n - 1) < n^2 < n(n + 1) < (n + 1)^2$.

* `IsComposite`: Defines composites as natural numbers $m$ satisfying $2 \le m \land \neg \text{Nat.Prime } m$.

* `composite_emergence_half_step_inevitability`:

  1. $\neg \text{Nat.Prime } 1 \land \text{Nat.Prime } 2$

  2. $\forall m \le 2, \neg \text{IsComposite } m$

  3. $\text{IsComposite } (2^2) \land \forall c, \text{IsComposite } c \to 2^2 \le c$

  4. $2 \le n \to \text{IsComposite } (n^2)$

* `structural_capacity_equilibrium` / `capacity_equilibrium_holds`: For $2 \le n$, proves $(0 : \mathbb{R}) < \text{Real.log } (n : \mathbb{R})$ and $\text{Real.log } ((n : \mathbb{R})^2) / \text{Real.log } (n : \mathbb{R}) = 2$.

### Step 3: Bridge to Conjecture Propositions

* `oppermann_left_energy_slots`: Finite set (`Finset ℕ`) of primes $p$ satisfying $n(n - 1) < p < n^2$.

* `oppermann_right_energy_slots`: Finite set (`Finset ℕ`) of primes $q$ satisfying $n^2 < q < n(n + 1)$.

* `OppermannConjectureStatement`: For all $n \ge 2$, primes exist in both $(n(n - 1), n^2)$ and $(n^2, n(n + 1))$.

* `ShiftedLegendreConjectureStatement`: For all $n \ge 2$, a prime exists in $((n - 1)^2, n^2)$.

* `oppermann_slots_nonempty_of_conjecture`: Derives `1 ≤ card` for both left and right slots from `OppermannConjectureStatement`.

* `prove_shifted_legendre_of_oppermann`: Derives `ShiftedLegendreConjectureStatement` from `OppermannConjectureStatement` and $(n - 1)^2 < n(n - 1)$ in `quadrilateral_theorem`.

## 3. Interactive Visualization Specification (HTML Dashboard)

The dashboard (`Primes, Composites & Step Pitch`) provides interactive browser-based inspection of cumulative prime and composite growth across $0.5$ and $1.0$ step intervals.

### 3.1 Controls and Metrics

* **Controls**:

  * $n_{\max}$ **Slider**: Adjusts the upper step index from $2$ to $150$ (default `5`).

  * **Step Toggle**: Selects `1.0` or `0.5` step size (default `0.5`).

  * **Composite Formula**: Displays $C(m) = \max(0, m - 1 - \pi(m))$ for $m \ge 2$.

* **KPI Cards**:

  * **Primes** $\pi(n_{\max}^2)$: Cumulative prime count up to $n_{\max}^2$.

  * **Composites** $C(n_{\max}^2)$: Cumulative composite count ($2 \le m \le n_{\max}^2$, non-prime).

  * **Napier** $n_{\max}^2 / \ln(n_{\max}^2)$: Napier logarithmic density value.

* **Step Density & Composite Chart**: Chart.js line chart plotting `Primes` $\pi(n^2)$, `Composites` $C(n^2)$, `2n - 2`, and `Napier` density.

* **Step Table**: Displays step $n$, point $n^2$, cumulative primes $\pi$, cumulative composites $C$, $2n - 2$, Napier value, and difference $\pi - (2n - 2)$.

## 4. Verification Criteria

1. **Zero-Sorry and No Custom Axioms**: No `sorry` or custom `axiom` declarations, verified against Lean 4 standard axioms (`propext`, `Quot.sound`, `Classical.choice`).

2. **Type Safety and Reproducibility**: Proofs complete cleanly using `omega`, `norm_num`, `field_simp`, `nlinarith`, `decide`, and `ring`, while sieve computation, chart rendering, and step tables update dynamically with slider and step changes.
