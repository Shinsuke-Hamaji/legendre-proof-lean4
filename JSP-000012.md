# System Requirements Specification: Formal Verification of Shifted Legendre's and Oppermann's Conjectures via Synchronized Infinity and 0.5-Step Symmetry

## 1. System Overview & Architectural Paradigm

This document defines the specifications for the formal verification system based on **Natural Mathematics** and **Lean 4** type theory, as well as the accompanying interactive visualization dashboard (`JSP-000012.html`), addressing **Shifted Legendre's Conjecture** (prime existence within $((n-1)^2, n^2)$) and the stronger **Oppermann's Conjecture** (simultaneous prime existence across both half-intervals $(n(n-1), n^2)$ and $(n^2, n(n+1))$).

### 1.1 Key Architecture & Innovations

* **Zero External Assumptions via Synchronized Infinity (`synchronized_infinity_principle`)**: Rather than introducing large external hypotheses, the system proves the Synchronized Infinity Principle directly from injective successor mappings (`Nat.succ.inj`) and constructs the 1D Synchronized Infinite Tree (`SynchronizedInfiniteTree1D`) with a verified generation ceiling (`generation1D t < n`).
* **Inevitable Base Rule & Napier Logarithmic Floor**: Grounded in the inevitable generation of the first prime `2` (`inevitable_first_prime_two`) within $(1^2, 2^2)$, the system establishes structural capacity equilibrium (`structural_capacity_equilibrium`) via the positivity of the natural logarithm (`0 < Real.log n`) for all $n \ge 2$.
* **0.5-Step Half-Interval Prime Generation Rule (`half_step_prime_generation_rule`)**: Synthesizes the 1D synchronized tree, the prime `2` base rule, and logarithmic capacity equilibrium to prove the structural containment of prime energy slots across the left $(n(n-1), n^2)$ and right $(n^2, n(n+1))$ half-intervals under inclusion-exclusion.
* **Propositional Bridge & Unified Corollary**: Connects the 0.5-step generation structure directly to the standard propositional statement of Oppermann's Conjecture (`prove_oppermann_structural_proposition`) and derives Shifted Legendre's Conjecture as an immediate corollary (`prove_shifted_legendre_of_oppermann`).
* **Strict Zero-Sorry Compliance**: Eliminates all `sorry`, `admit`, and custom `axiom` declarations, relying exclusively on Lean 4's standard foundational axioms (`[propext, Classical.choice, Quot.sound]`).

## 2. Internal Dependency Architecture (`JSP-000012.lean`)

All definitions and theorems are encapsulated within the `NaturalMathematics` namespace and verified in a strict bottom-up dependency chain:

  * `half_step_prime_generation_rule` — Proves `HalfStepPrimeGenerationStructure n` for all $n \ge 2$ without external hypotheses.

## 3. Interactive Viewer Specification (`JSP-000012.html`)

The interactive dashboard provides real-time visual verification comparing observed cumulative primes $\pi(n^2)$ against Napier logarithmic density and the linear $2n - 2$ floor across integer and half-step grids.

### 3.1 Core UI Components

* **Index Upper Bound Slider ($n_{\max}$)**: Dynamically adjusts the upper index bound (default: `10`) and recalculates square-interval prime metrics in real time.
* **Gnomon Resolution / Step Mode Toggle (`1.0` vs `0.5`)**:
  * **Step: 1.0 (Integer)**: Evaluates standard integer square boundaries $n^2$.
  * **Step: 0.5 (Half-Step / Symmetry — Default)**: Maps half-integer symmetry points $(n + 0.5)$ starting from $n = 1$ to analyze micro-interval prime density across left and right half-intervals.
* **KPI Summary Cards**:
  * **Final Observed $\pi(n_{\max}^2)$**: Total observed primes up to the square limit $n_{\max}^2$.
  * **Napier Density Theory Value**: Theoretical baseline computed as $n_{\max}^2 / \ln(n_{\max}^2)$.
* **Step-Resolution Synchronized Density Chart**: Multi-series chart plotting observed cumulative $\pi$, Napier Density, and the Log base n Line ($2n - 2$).
* **Comparison Data Table (Gnomon Resolution View)**: Displays step-by-step rows for `Index / Step (n)`, `Effective Point (n^2 or interpolated)`, `Observed Cumulative π`, `Log base n Line (2n - 2)`, `Napier Density`, and `Difference`.
