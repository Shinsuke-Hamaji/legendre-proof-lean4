# System Requirements Specification: Formal Verification of Synchronized Infinity, 0.5-Pitch Square Composite Generation, and Oppermann / Shifted Legendre Conjectures

## 1. System Overview and Architecture

This specification defines the Lean 4 formalization under the `NaturalMathematics` namespace and the interactive HTML visualization dashboard comparing cumulative primes $\pi(n^2)$, cumulative composites $C(n^2)$, the linear baseline $2n - 2$, and the Napier logarithmic density $n^2 / \ln(n^2)$ across $0.5$ and $1.0$ step resolutions.

### 1.1 Key Highlights

* **1D Synchronized Infinity Tree Dependency in Propositions and Proofs**:
  Rather than leaving the inductive tree (`SynchronizedInfiniteTree1D`) and generation bounds (`generation1D`, `generation_sync_1d_lt_value`, and `ramanujacharyulu_synchronized_1d_tree`) as isolated definitions, they are integrated directly into `OppermannConjectureStatement`, `ShiftedLegendreConjectureStatement`, `oppermann_slots_nonempty_of_conjecture`, and `prove_shifted_legendre_of_oppermann`, grounding the formalization in synchronized infinite progression within `NaturalMathematics`.

* **Separation of `1` vs. `2` via Prime Definition and 0.5-Pitch Composite Emergence**:
  Because Peano-style sequence generation (`1`, `2`, $\dots$) alone does not distinguish the structural role of `1` from `2`, the prime predicate (`Nat.Prime`) separates non-prime `1` ($\neg \text{Nat.Prime } 1$) from the first prime `2` ($\text{Nat.Prime } 2$). Building on this, `composite_emergence_half_step_inevitability` proves that no composite (`IsComposite`) exists in the `1-2` regime ($m \le 2$), advancing by a $0.5$ square pitch into `1-2-3-4` ($2^2 = 4$) yields the minimal composite $4 = 2^2$, and $n^2$ is composite for every $n \ge 2$.

* **Clean Propositional Proofs with Zero Custom Axioms or `sorry`**:
  Without introducing ad-hoc axioms or `sorry`, the formalization proves the Synchronized Infinity Principle (`synchronized_infinity_principle`), the 1D Synchronized Infinite Tree (`SynchronizedInfiniteTree1D`), square-rectangle partitioning and strict nesting (`quadrilateral_theorem`), and Napier logarithmic capacity equilibrium $\log_n(n^2) = 2$ (`capacity_equilibrium_holds`).

* **Implicational Bridges to Oppermann's and Shifted Legendre's Conjectures**:
  Assuming `OppermannConjectureStatement` over `SynchronizedInfiniteTree1D n`, the formalization proves that both left and right prime slots (`oppermann_left_energy_slots` and `oppermann_right_energy_slots`) have cardinality at least `1` (`oppermann_slots_nonempty_of_conjecture`) and derives `ShiftedLegendreConjectureStatement` (`prove_shifted_legendre_of_oppermann`).

## 2. Lean 4 Formalization Specification (`NaturalMathematics`)

### Step 1: Synchronized Infinity & 1D Tree

* `synchronized_infinity_principle`: Directly proves infinitude via injectivity of $f(x) = x + 1$ and non-reachability of `0` without external assumptions.

* `SynchronizedInfiniteTree1D`: Inductive definition of 1D progression with `root` ($n = 1$) and `step`.

* `generation1D` / `generation_sync_1d_lt_value`: Proves by induction that generation depth always satisfies `generation1D t < n`.

* `ramanujacharyulu_synchronized_1d_tree`: Proves that for every $n \ge 1$, there exists a tree node satisfying `generation1D t = n - 1 ∧ generation1D t < n`.

### Step 2: Square Geometry, Prime Separation (1 vs 2), 0.5-Pitch Composite Emergence, & Logarithmic Equilibrium

* `quadrilateral_theorem`: For $2 \le n$, proves the partitions $n^2 = n(n - 1) + n$ and $n(n + 1) = n^2 + n$, as well as strict nesting $(n - 1)^2 < n(n - 1) < n^2 < n(n + 1) < (n + 1)^2$.

* `IsComposite`: Defines composite numbers as $2 \le m \land \neg \text{Nat.Prime } m$.

* `composite_emergence_half_step_inevitability`:

  1. $\neg \text{Nat.Prime } 1 \land \text{Nat.Prime } 2$

  2. $\forall m \le 2, \neg \text{IsComposite } m$

  3. $\text{IsComposite } (2^2) \land \forall c, \text{IsComposite } c \to 2^2 \le c$

  4. $2 \le n \to \text{IsComposite } (n^2)$

* `structural_capacity_equilibrium` / `capacity_equilibrium_holds`: For $2 \le n$, proves $(0 : \mathbb{R}) < \text{Real.log } (n : \mathbb{R})$ and $\text{Real.log } ((n : \mathbb{R})^2) / \text{Real.log } (n : \mathbb{R}) = 2$.

### Step 3: Synchronized-Tree-Dependent Propositional Bridge (Oppermann & Legendre)

* `oppermann_left_energy_slots`: Finite set (`Finset ℕ`) of primes $p$ satisfying $n(n - 1) < p < n^2$.

* `oppermann_right_energy_slots`: Finite set (`Finset ℕ`) of primes $q$ satisfying $n^2 < q < n(n + 1)$.

* `OppermannConjectureStatement`: States that for all $n \ge 2$ and `SynchronizedInfiniteTree1D n`, primes exist in both $(n(n - 1), n^2)$ and $(n^2, n(n + 1))$.

* `ShiftedLegendreConjectureStatement`: States that for all $n \ge 2$ and `SynchronizedInfiniteTree1D n`, a prime exists in $((n - 1)^2, n^2)$.

* `oppermann_slots_nonempty_of_conjecture`: Obtains a synchronized tree node and generation bound via `ramanujacharyulu_synchronized_1d_tree` and `generation_sync_1d_lt_value`, deriving cardinality $\ge 1$ for both left and right slots from `OppermannConjectureStatement`.

* `prove_shifted_legendre_of_oppermann`: Uses `ramanujacharyulu_synchronized_1d_tree`, `generation_sync_1d_lt_value`, `OppermannConjectureStatement`, and $(n - 1)^2 < n(n - 1)$ from `quadrilateral_theorem` to derive `ShiftedLegendreConjectureStatement`.

## 3. Interactive Visualization Specification (HTML Dashboard)

The dashboard (`Primes, Composites & Step Pitch`) provides browser-based interactive inspection of cumulative prime and composite growth across `0.5` and `1.0` step resolutions.

### 3.1 Controls and Metrics

* **Controls**:

  * $n_{\max}$ **Slider**: Adjusts the upper step bound over $2 \sim 150$ (default: `5`).

  * **Step Toggle**: Selects `1.0` or `0.5` (default: `0.5`) step increments.

  * **Composite Count Formula**: Displays $C(m) = \max(0, m - 1 - \pi(m))$ for $m \ge 2$.

* **KPI Cards**:

  * **Primes** $\pi(n_{\max}^2)$: Cumulative prime count up to $n_{\max}^2$.

  * **Composites** $C(n_{\max}^2)$: Count of composite (non-prime $\ge 2$) integers up to $n_{\max}^2$.

  * **Napier** $n_{\max}^2 / \ln(n_{\max}^2)$: Napier logarithmic density value.

* **Step Density & Composite Chart**: Chart.js line plot displaying `Primes` $\pi(n^2)$, `Composites` $C(n^2)$, `2n - 2`, and `Napier` density.

* **Step Table**: Tabular view of step $n$, point $n^2$, cumulative primes $\pi$, cumulative composites $C$, $2n - 2$, Napier value, and difference $\pi - (2n - 2)$.

## 4. Verification Criteria

1. **Zero-Sorry / No Custom Axioms**: No `sorry` or custom `axiom` declarations, verified using standard Lean 4 kernel axioms (`propext`, `Quot.sound`, `Classical.choice`).

2. **Type Safety and Reproducibility**: All Lean proofs (`omega`, `norm_num`, `field_simp`, `nlinarith`, `decide`, `ring`) build without errors, and the browser sieve, chart, and table update dynamically with slider and step mode changes.
