# System Requirements Specification: Unconditional Formal Verification of Prime-Definition-Driven 0.5-Pitch Generation and Composite Filling

## 1. System Overview and Architecture

This specification defines the latest Lean 4 formal verification codebase based on the Natural Mathematics reference system (`NaturalMathematics`)—completely free of external axioms, custom internal assumptions, `sorry`, or unproved conjecture hypotheses—and the interactive visualization dashboard (HTML) that contrasts cumulative primes $\pi(n^2)$, cumulative composites $C(n^2)$, the linear baseline $2n - 2$, and Napier logarithmic density $n^2 / \ln(n^2)$ at $0.5$ and $1.0$ step resolutions.

### 1.1 Key Highlights (Major Revisions from Previous Version)

* **Elimination of Hardcoded Tables; Unconditional Derivation of the $0.5$ Pitch ($k = 1 \to 1.5 \to 2$) from the Definition of Primes**:
  The manual lookup function (formerly `PitchAnchorValue`) has been completely removed. Instead, the necessity of the $0.5$ pitch is proved unconditionally from the Peano progression, the definition of prime numbers (`Nat.Prime`), and the definition of composite numbers (`IsComposite`).
  * **Absence of Composites in $1 - 2 - 3$ (`no_composite_in_peano_three`)**: Within the initial Peano sequence $m \le 3$, only $1$ (unit origin), $2$ (prime), and $3$ (prime) appear; no composite number can be derived.
  * **Necessary and Sufficient Condition for Composite Emergence (`composite_emergence_requires_four`)**: A composite number emerges if and only if ($\leftrightarrow$) the sequence reaches $4 = 2^2$ (i.e., $1 - 2 - 3 - 4$).
  * **Necessity of the $0.5$ Pitch (`prime_definition_forces_half_pitch_progression`)**: For the minimal prime base $n = 2$, prime $3$ lies strictly between $2^1 = 2$ (minimal prime) and $2^2 = 4$ (minimal composite), i.e., $2^1 < 3 < 2^2$. Jumping by an integer exponent increment ($\Delta k = 1$) skips over $3$. Consequently, capturing the 3-stage emergence ($2 \to 3 \to 4$) so that composite filling can enter requires a **$0.5$ pitch ($1 \to 1.5 \to 2$)** as $k$ progresses from $1$ to $2$.
* **Transition to a Completely Unconditional Proof (Removal of Conjecture Hypotheses)**:
  The external hypothesis argument (formerly `h_opp : OppermannConjectureStatement`) in Step 3 has been completely eliminated. The updated Step 3 (`step3_from_proved_theorems`) assumes no unproved mathematical conjectures and is derived unconditionally from the theorems proved in Step 1 and Step 2.
* **Clean Dependency Structure with Zero External Axioms, Custom Assumptions, or `sorry`**:
  All theorems rely exclusively on standard Lean 4 / Mathlib foundational axioms (`propext`, `Classical.choice`, `Quot.sound`), with zero custom `axiom` declarations, `sorry` placeholders, or arbitrary initial constants.

## 2. Lean 4 Formal Verification Specification (`NaturalMathematics`)

### Step 1: Peano Root & 1D Synchronized Infinite Tree (No Internal Assumptions)
* `synchronized_infinity_principle`: Proves infinity directly without external assumptions via the injectivity of $f(x) = x + 1$ and the unreachability of `0` (Axiom dependencies: `[propext]`).
* `SynchronizedInfiniteTree1D`: Inductive definition of 1D progression rooted at `root` ($n = 1$) via `step`.
* `generation1D` / `generation_sync_1d_lt_value`: Proves by induction that tree generation depth strictly satisfies `generation1D t < n`.
* `ramanujacharyulu_synchronized_1d_tree`: Proves that for every $n \ge 1$, there exists a tree node satisfying `generation1D t = n - 1 ∧ generation1D t < n` (Axiom dependencies: `[propext]`).

### Step 2: Necessity of $0.5$ Pitch, Composite Emergence, Square Geometry & Logarithmic Equilibrium (No Internal Assumptions)
* `IsComposite`: Defines composite numbers as $2 \le m \land \neg \text{Nat.Prime } m$.
* `no_composite_in_peano_three`: Proves $\forall m \le 3, \neg \text{IsComposite } m$, establishing that no composite number can be derived in $1 - 2 - 3$ (Axiom dependencies: `[propext]`).
* `composite_emergence_requires_four`: Proves $(\exists m \le N, \text{IsComposite } m) \leftrightarrow 4 \le N$, establishing the equivalence between composite emergence and reaching $1 - 2 - 3 - 4$ (Axiom dependencies: `[propext]`).
* `prime_definition_forces_half_pitch_progression`: Unconditionally proves the following conjunction for any $2 \le n$ (Axiom dependencies: `[propext, Classical.choice, Quot.sound]`):
  1. $\forall m \le 3, \neg \text{IsComposite } m$ (no composites in $1 - 2 - 3$)
  2. $\text{IsComposite } (2^2) \land (\forall c, \text{IsComposite } c \to 2^2 \le c)$ ($4 = 2^2$ is the unique minimal composite)
  3. $\exists p, \text{Nat.Prime } p \land 2^1 < p \land p < 2^2$ (prime $3$ lies strictly between $2^1$ and $2^2$)
  4. $n^1 < n^2 \land 2 \le n^2 - n^1$ (existence of an interior gap between $n^1$ and $n^2$ for all $n \ge 2$)
  5. $(1 : \mathbb{R}) + 0.5 = 1.5 \land (1.5 : \mathbb{R}) + 0.5 = 2 \land 1 < 1.5 \land 1.5 < 2$ (3-stage bisection via the $0.5$ pitch)
  6. $\text{IsComposite } (n^2)$ (compositeness of $n^2$ for all $n \ge 2$)
* `quadrilateral_theorem`: Proves $n^2 = n(n - 1) + n$, $n(n + 1) = n^2 + n$, and the nested ordering $(n - 1)^2 < n(n - 1) < n^2 < n(n + 1) < (n + 1)^2$ for $2 \le n$ (Axiom dependencies: `[propext]`).
* `structural_capacity_equilibrium` / `capacity_equilibrium_holds`: Proves $(0 : \mathbb{R}) < \text{Real.log } (n : \mathbb{R})$ and $\text{Real.log } ((n : \mathbb{R})^2) / \text{Real.log } (n : \mathbb{R}) = 2$ for $2 \le n$ (Axiom dependencies: `[propext, Classical.choice, Quot.sound]`).

### Step 3: Direct Unconditional Derivation from Proved Step 1 & Step 2 Theorems (No External or Conjecture Hypotheses)
* `step3_from_proved_theorems`: For any $2 \le n$, without assuming any unproved conjectures (such as Oppermann's conjecture), directly synthesizes the results of `ramanujacharyulu_synchronized_1d_tree`, `prime_definition_forces_half_pitch_progression`, `quadrilateral_theorem`, and `capacity_equilibrium_holds` to prove unconditionally that the following hold simultaneously (Axiom dependencies: `[propext, Classical.choice, Quot.sound]`):
  1. Existence and generation bound of the 1D synchronized infinite tree (`generation1D t = n - 1 ∧ generation1D t < n`)
  2. Absence of composites in the Peano $1 - 2 - 3$ range ($\forall m \le 3, \neg \text{IsComposite } m$)
  3. Compositeness of squares for all $n \ge 2$ ($\text{IsComposite } (n^2)$)
  4. Square-rectangle nested inequalities ($(n - 1)^2 < n(n - 1) < n^2 < n(n + 1) < (n + 1)^2$)
  5. Logarithmic scaling equilibrium (`structural_capacity_equilibrium n`)

## 3. Interactive Visualization Specification (HTML Dashboard)

The dashboard (`Primes, Composites & Step Pitch`) provides an interactive browser-based environment to inspect cumulative prime and composite progressions and composite filling at $0.5$ and $1.0$ step resolutions.

### 3.1 UI Components and Metric Definitions
* **Controls Panel**:
  * **$n_{\max}$ Slider**: Dynamically adjusts the upper step bound $n_{\max}$ (initial value: `5`).
  * **Step Toggle**: Switches between `1.0` and `0.5` (initial value: `0.5`) to inspect half-integer pitch resolution.
  * **Composite Count Formula Display**: Explicitly displays $C(m) = \max(0, m - 1 - \pi(m))$ for $m \ge 2$.
* **KPI Summary Cards (3 Metrics)**:
  * **Primes $\pi(n_{\max}^2)$**: Cumulative prime count up to $n_{\max}^2$.
  * **Composites $C(n_{\max}^2)$**: Cumulative non-prime integer count $\ge 2$ up to $n_{\max}^2$.
  * **Napier $n_{\max}^2 / \ln(n_{\max}^2)$**: Napier logarithmic density value.
* **Step Density & Composite Chart**:
  * Visualizes `Primes π`, `Composites C`, the linear baseline `2n - 2`, and `Napier` logarithmic density across the progression of $n$.
  * Under the `0.5` step mode, visually confirms that composites remain zero across $1 - 2 - 3$ and initiate composite filling precisely upon reaching $4 = 2^2$, continuing consistently thereafter.
* **Step Table**:
  * Tabulates each step $n$ (`Step (n)`), evaluation point $n^2$ (`Point (n²)`), cumulative primes $\pi$ (`Primes π`), cumulative composites $C$ (`Composites C`), linear baseline $2n - 2$ (`2n - 2`), Napier density (`Napier`), and the difference $\pi - (2n - 2)$ (`π - (2n-2)`).

   All tactic proofs (`omega`, `norm_num`, `field_simp`, `nlinarith`, `decide`, `ring`) must compile with zero errors or warnings, and the numerical outputs in the HTML dashboard chart and table must strictly match the boundary conditions proved in Lean ($0$ composites for $m \le 3$, and first composite emergence at $4 = 2^2$).
