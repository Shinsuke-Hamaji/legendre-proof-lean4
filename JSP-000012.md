# System Requirements Specification: Formal Verification of 0.5-Pitch Generation & Composite Filling Determined by the Prime Definition, and Propositional Bridges to Oppermann's and Shifted Legendre's Conjectures

## 1. System Overview and Architecture

This specification defines the Lean 4 formal proof suite under the natural mathematics reference namespace (`NaturalMathematics`)—with zero custom axioms, zero internal assumptions, and zero `sorry`s—together with an interactive HTML visualization dashboard (`Primes, Composites & Step Pitch`) that contrasts cumulative primes $\pi(n^2)$, cumulative composites $C(n^2)$, the linear baseline $2n - 2$, and Napier logarithmic density $n^2 / \ln(n^2)$ at $0.5$ / $1.0$ step resolution.

### 1.1 Key Highlights

* **0.5-Pitch and Mutual Catch-Up Determined Internally by the Prime Definition (**$1 \to 1.5 \to 2$**)**:
  Rather than imposing a generative pitch externally, introducing the prime definition (`Nat.Prime`) on top of Peano successor progression (rooted at $1$) internally determines a $0.5$-step pitch (indexed by $k = 2, 3, 4, \dots$, corresponding to $n = k / 2 = 1.0, 1.5, 2.0, \dots$).

  * $k = 2$ ($n = 1.0$): Natural origin $1$ ($\neg \text{Nat.Prime } 1$).

  * $k = 3$ ($n = 1.5$): Emergence of the first prime $2$ ($\text{Nat.Prime } 2$). At this initial prime-2 pitch, no composites have appeared yet ($m \le 2$), and one side alone cannot keep pace with the full generative progression.

  * $k = 4$ ($n = 2.0$): Prime $3$ and the minimal composite $4 = 2^2$ emerge together, initiating mutual catch-up where composite filling covers gaps that prime branching alone does not fill.

  * All integer boundaries $n \ge 2$: The same generative rule continues unchanged across the progression, guaranteeing `IsComposite (n ^ 2)` for every $n \ge 2$ (`prime_definition_determines_pitch_and_composite_filling`).

* **Clean Dependency Structure with Zero Custom Axioms and Zero `sorry`s**:
  No custom `axiom` declarations or `sorry` placeholders are used. All theorems depend only on standard Lean 4 / Mathlib axioms (`propext`, `Classical.choice`, `Quot.sound`), connecting Step 1 (1D synchronized infinite tree), Step 2 (prime-definition-determined pitch, mutual catch-up, square geometry, and logarithmic equilibrium), and Step 3 (conjecture bridges).

* **Propositional Statements Dependent on the 1D Synchronized Infinite Tree**:
  The inductive tree (`SynchronizedInfiniteTree1D`) and its generation depth bounds (`generation1D`, `generation_sync_1d_lt_value`, and `ramanujacharyulu_synchronized_1d_tree`) are woven into `OppermannConjectureStatement`, `ShiftedLegendreConjectureStatement`, `oppermann_slots_nonempty_of_conjecture`, and `prove_shifted_legendre_of_oppermann`, grounding the conjecture bridges in synchronized infinite progression.

## 2. Lean 4 Formal Proof Specification (`NaturalMathematics`)

### Step 1: Peano Root and 1D Synchronized Infinite Tree (No Internal Assumptions)

* `synchronized_infinity_principle`: Directly proves infinity without external assumptions via injectivity of $f(x) = x + 1$ and non-reachability of `0` (depends only on `[propext]`).

* `SynchronizedInfiniteTree1D`: Inductive type representing 1D progression starting from `root` ($n = 1$) via `step`.

* `generation1D` / `generation_sync_1d_lt_value`: Proves by induction that generation depth always satisfies `generation1D t < n`.

* `ramanujacharyulu_synchronized_1d_tree`: Proves that for every $n \ge 1$, there exists a tree node satisfying `generation1D t = n - 1 ∧ generation1D t < n` (depends only on `[propext]`).

### Step 2: Prime-Definition-Determined 0.5-Pitch, Mutual Catch-Up, Square Geometry, and Log Equilibrium (No Internal Assumptions)

* `IsComposite`: Defined as $2 \le m \land \neg \text{Nat.Prime } m$.

* `PitchAnchorValue`: Anchor value function for half-integer pitch index $k$ ($n = k / 2$), defined with `if-then-else` and `@[simp]` lemmas (`pitchAnchorValue_two`, `pitchAnchorValue_three`, `pitchAnchorValue_four`) for reliable simplification:

  * `PitchAnchorValue 2 = 1` ($n = 1.0$: natural unit $1$)

  * `PitchAnchorValue 3 = 2` ($n = 1.5$: prime $2$)

  * `PitchAnchorValue 4 = 4` ($n = 2.0$: minimal composite $4 = 2^2$)

  * `PitchAnchorValue k = (k / 2) ^ 2` (general branch)

* `prime_definition_determines_pitch_and_composite_filling`: For all $2 \le n$, proves in one unified theorem (depends on `[propext, Classical.choice, Quot.sound]`):

  1. $\neg \text{Nat.Prime } (\text{PitchAnchorValue } 2) \land \text{Nat.Prime } (\text{PitchAnchorValue } 3)$ (separation of $1$ and $2$ by the prime definition)

  2. $\forall m \le \text{PitchAnchorValue } 3, \neg \text{IsComposite } m$ (absence of composites at $n = 1.5$, where one side alone cannot catch up)

  3. $\exists c, \text{PitchAnchorValue } 3 < c \land c \le \text{PitchAnchorValue } 4 \land \text{IsComposite } c$ (composite emergence by $n = 2.0$)

  4. $\text{Nat.Prime } 3 \land \text{IsComposite } (\text{PitchAnchorValue } 4) \land (\forall c, \text{IsComposite } c \to \text{PitchAnchorValue } 4 \le c)$ (joint emergence of prime $3$ and minimal composite $4$)

  5. $\text{IsComposite } (n^2)$ (invariant composite emergence for all $n \ge 2$)

* `quadrilateral_theorem`: For $2 \le n$, proves $n^2 = n(n - 1) + n$, $n(n + 1) = n^2 + n$, and $(n - 1)^2 < n(n - 1) < n^2 < n(n + 1) < (n + 1)^2$.

* `structural_capacity_equilibrium` / `capacity_equilibrium_holds`: For $2 \le n$, proves $(0 : \mathbb{R}) < \text{Real.log } (n : \mathbb{R})$ and $\text{Real.log } ((n : \mathbb{R})^2) / \text{Real.log } (n : \mathbb{R}) = 2$.

### Step 3: Synchronized-Tree-Dependent Propositional Bridges (Connected via Hypothesis Argument)

* `oppermann_left_energy_slots`: Finite set (`Finset ℕ`) of primes $p$ satisfying $n(n - 1) < p < n^2$.

* `oppermann_right_energy_slots`: Finite set (`Finset ℕ`) of primes $q$ satisfying $n^2 < q < n(n + 1)$.

* `OppermannConjectureStatement`: States that for every $n \ge 2$ and `SynchronizedInfiniteTree1D n`, primes exist in both $(n(n - 1), n^2)$ and $(n^2, n(n + 1))$.

* `ShiftedLegendreConjectureStatement`: States that for every $n \ge 2$ and `SynchronizedInfiniteTree1D n`, a prime exists in $((n - 1)^2, n^2)$.

* `oppermann_slots_nonempty_of_conjecture`: Uses `ramanujacharyulu_synchronized_1d_tree` and `generation_sync_1d_lt_value` to obtain tree witnesses and bounds, deriving cardinality $\ge 1$ for both left and right slots from `h_opp : OppermannConjectureStatement`.

* `prove_shifted_legendre_of_oppermann`: Combines `ramanujacharyulu_synchronized_1d_tree`, `generation_sync_1d_lt_value`, `h_opp : OppermannConjectureStatement`, and $(n - 1)^2 < n(n - 1)$ from `quadrilateral_theorem` to derive `ShiftedLegendreConjectureStatement`.

## 3. Interactive Visualization Specification (HTML Dashboard)

The dashboard (`Primes, Composites & Step Pitch`) provides an interactive browser view of cumulative prime and composite growth and mutual catch-up across $0.5$ and $1.0$ step resolutions.

### 3.1 UI Components and Metrics

* **Controls**:

  * $n_{\max}$ **Slider**: Adjusts the upper step bound from $2$ to $150$ (default: `5`).

  * **Step Selector**: Radio toggle between `1.0` and `0.5` (default: `0.5`).

  * **Composite Count Formula**: Displays $C(m) = \max(0, m - 1 - \pi(m))$ for $m \ge 2$.

* **KPI Cards**:

  * **Primes** $\pi(n_{\max}^2)$: Cumulative prime count up to $n_{\max}^2$.

  * **Composites** $C(n_{\max}^2)$: Cumulative non-prime count for integers $\ge 2$ up to $n_{\max}^2$.

  * **Napier** $n_{\max}^2 / \ln(n_{\max}^2)$: Napier logarithmic density value.

* **Step Density & Composite Chart**:

  * Chart.js line chart plotting `Primes π(n²)` (emerald), `Composites C(n²)` (rose), `2n - 2` (amber dashed), and `Napier` density (purple dotted) from $n = 1.0$ to $n_{\max}$, illustrating the initial transition $1.0 \to 1.5 \to 2.0$ ($\pi=0,C=0 \to \pi=1,C=0 \to \pi=2,C=1$) and subsequent composite filling.

* **Step Table**:

  * Lists step $n$, effective point $n^2$, cumulative primes $\pi$, cumulative composites $C$, baseline $2n - 2$, Napier value, and difference $\pi - (2n - 2)$ (all rows for $n \le 15$, sampled with endpoint thereafter).
